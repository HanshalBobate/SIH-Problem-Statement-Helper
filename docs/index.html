QUICKSTART

Up and Running in 3 Steps

Get the complete productivity layer active on your browser in less than two minutes.

1

Start Python Backend

Launch the async FastAPI storage server to persist all your notes in SQLite.

POWERSHELL / BASH
cd backend
python server.py
2

Launch Ollama (CORS)

Allow the browser extension to stream local LLM inference directly from Ollama.

WINDOWS (POWERSHELL)
$env:OLLAMA_ORIGINS="*"
ollama serve
3

Load Extension

Open chrome://extensions, enable Developer mode, and click Load unpacked on the extension/ folder.

TARGET DIRECTORY
📁 /SIH_Website_Helper/extension
